# Support and contributions

Use [GitHub issues](https://github.com/endcorp-hq/open-data-examples/issues)
for conversion, access and documentation problems. Include the collection,
public release snapshot, selected dates/region, package versions and a small
reproducer. Do not post credentials, account identifiers or private data.

Scientific product questions belong with the upstream producer linked in the
[source guide](endcorp-sst/source-rights.md). Before opening a pull request,
check that notebook outputs contain no credentials or private paths, preserve
source attribution and describe how the example was tested. Keep reads bounded
to a small date range and region. Contributions are provided under this
repository's MIT license, excluding upstream material under separate terms.
